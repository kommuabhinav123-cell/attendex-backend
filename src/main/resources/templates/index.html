About Attendex

Engineered for Academic Institutions

Attendex is a full-stack Java attendance portal designed to eliminate paper-based logs and fragmented spreadsheets. It brings administrators, professors, and students onto a unified, transparent platform.

  • Spring Boot 3 & Java 21 core architecture
  • BCrypt password hashing & CSRF protection
  • Fully responsive interface for mobile and desktop
Enterprise Security & Access

Institution accounts are safeguarded with industry-standard role-based controls:

  • Centralized Provisioning: Accounts are assigned and managed by institution administrators.
  • BCrypt Password Hashing: Credentials are encrypted with salted one-way hashing.
  • Zero Public Exposure: Account credentials are kept strictly private.
